# 快捷键雷达 v1

已确认视觉：`concept-v1.png`。客户端采用原生控件实现对应布局，概念图不进入运行时，也不烘焙应用、用途、数量或状态。

## 行为与来源

- 独立功能池入口 `shortcutRadar`，复用添加、移除、重排和启停；未添加不创建实例，开启不自动检测。当前按默认构建的内置模块方式接入，不宣称已完成独立二进制下载。
- 手动“检测一次”：读取本应用当前启用的组合键和登记状态、Carbon 系统登记项、最多 32 个运行中的普通或菜单栏应用（普通应用优先）公开且启用的菜单项。不会打开菜单、激活应用、遍历磁盘或读应用正文。
- 公开 AX 菜单读取在单一后台队列执行；每次最多 8 秒，每应用 0.8 秒，单次消息超时 0.1 秒，每应用最多 800 节点和 8 层，所有来源最多 4096 项。未读到、超时、缺少权限及截断均如实显示覆盖情况。
- 系统 API 不提供用途名称，显示“系统快捷键（用途未公开）”，不按未验证的数字编号猜用途。
- 按已知用途数量从高到低排序。同数时优先疑似全局冲突；不同应用中的本地命令重复不直接视为冲突。重复 AX 来源去重，作用范围以来源可证明的范围为准。
- 支持组合键符号、`Control + Shift + R` 等文本，以及应用／用途关键词；应用搜索命中后保留该组合的其他已知来源。上下键选择，Enter 聚焦用途列表。
- 搜索框键盘按钮只在明确进入时采集一个组合键，期间暂停本应用快捷键，退出、失焦、关闭或导航时恢复；不新增全局监听，不保存按键历史。第三方快捷键仍可能响应。
- 输入组合键后点击检测，会立即注册并释放一次排他探测。**实测普通共享登记可以通过这项探测，另一进程的排他登记会返回占用**。因此成功不代表空闲，显示“未检测到排他占用 · 仍可能有共享登记或后台监听”；未知归属不计为一个额外用途，避免重复统计。
- 在内存保留一次检测结果及最多 32 个 64×64 RGBA 图标（像素合计最多 512 KiB，不持有原始大图）；没有辅助功能权限时不获取这些图标。移除、停用、退出释放缓存和任务；离开页面取消当前任务。无定时刷新、空闲扫描、账号、网络、数据库或自动修改第三方快捷键。

## 验收

- `swift test --disable-keychain`：包含组合键归一化、范围与误报、来源去重、查询、过滤、数量上限等核心用例。
- `zsh tools/run-shortcut-radar-regression.sh --live-seed --probe-registration --output dist/shortcut-radar-preview`：原生控件宽窄排版、整行鼠标选择、键盘捕获及释放、搜索筛选、取消／重启／过期结果、真实系统枚举与两个测试进程间的登记探测。所有测试使用独立 fixture，不写安装版偏好，不模拟系统按键、不更改 TCC。
- `zsh tools/run-settings-switcher-regression.sh`：功能池全部模块、卡片比例、原生控件回归。
- 实际运行中第三方应用的可读范围依赖 macOS 的辅助功能授权及应用公开的 AX 信息。离屏预览、模拟数据和读取系统登记不能代替用户真实机器上的完整跨应用验证。
