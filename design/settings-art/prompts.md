# Image-backed native settings

Built-in imagegen, reference-led edits. The PNG files contain decoration and static labels only. The app overlays real native key recorders, radio choices, toggles, directory selection and recording result controls. Both assets are lazy-loaded once; narrow windows use native sections.

Assets: `Resources/SettingsCaptureBoard.png` and `Resources/SettingsSwitcherBoard.png`, both 1774 × 887 pixels. The switcher uses the source region with top 185 and bottom 820; normalized native positions are defined in `SettingsBoardView.swift`.

## Capture prompt

Use case: precise-object-edit. Input image is the edit target: the supplied two-window pencil/crayon macOS settings reference. Create a production UI backdrop from ONLY the UPPER screenshot/recording window BODY, excluding the title bar, traffic lights, outer window border and lower window. Preserve exactly the beautiful warm paper, fine pencil linework, watercolor/crayon mountain lake illustrations, torn pale-yellow sticky note, blue and coral arrows and thin three-column divider lines. Output a clean flat full-canvas landscape body panel, aspect ratio about 2:1, no perspective, no exterior margins, 1600x800 preferred. Top three columns: '截图', '贴图', '录屏'. At top of each column preserve the empty pencil keycap outline but remove F1/F3/chord text. Keep the blue arrow physically connecting each keycap to its illustration and red arrow for recording. Keep the note '随手贴上 更高效'. In middle column retain the two mountain small previews and static labels '无边缘' '白光', but REMOVE any checkmark/selected highlight. Under them keep an EMPTY pencil keycap and arrow to label '显示 / 隐藏'. Under capture and recording pictures remove the fixed hotkey captions completely, leaving blank room for real labels. Bottom band retain only line and static labels '保存位置' and '最近录屏', plus EMPTY outlined path field and EMPTY outlined choose-folder button at left; on right remove recorded filename/date/thumbnail and leave blank space for real result controls. Do not draw any enabled switches, status values, filenames, dates, shortcut characters, native fake cursors, or character mascots. Exact composition and style from reference, preserve mountain richness. This is an image-backed UI whose empty regions receive real native controls, not a complete screenshot.
