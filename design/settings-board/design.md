# Settings board\n\nConcept illustration only. Native editable text, live states and saved shortcuts are implemented separately. Default 960 × 640 client shows common controls without outer scrolling; narrow windows use a vertical fallback. Prompt preview continues to use the runtime PromptWheelView.\n\nImage generation prompt:\n\nUse case: ui-mockup. Create a clean concept sheet for three macos-x desktop settings pages, arranged vertically on one sheet, each wide compact window same width. Realistic implementable native app layout drawn in gentle pencil and crayon on warm paper white. Soft thin irregular graphite lines, small blue green lavender and coral strokes, no people, no mascot, no heavy black borders, no glossy buttons, no gradients, no dense decorations. Clear readable Chinese labels, short text only. The illustrations ARE the interactive options, not a banner above duplicate form controls. No outer page scrollbar; each window is a compact one-screen control board. Shortcuts appear as little editable keycaps with a hand-drawn curved arrow pointing to the exact function illustration.
