# 0.0.120 性能与缺陷审查

基线为已发布 0.0.119（708b358），不包含工作区未发布的模块化、录屏及旧镜像抽屉实验。未操作用户界面、安装版、剪贴板或真实图标。

## 确定并修复

1. MenuBarNativeShelf 的 Command-drag 分派错误地位于普通鼠标移动分支，而该分支明确排除 leftMouseDragged，也无法收到 down/up。内部状态测试通过不能证明入口连通。修复为在非合并的原始按下/拖动/松开队列中处理；原事件仍原样交给系统。新增本进程 NSEvent 入口回归（不 post），修复前失败，修复后通过。
2. 全部显示没有取消未完成的边界读取，晚到结果能够重新设置 wantsCollapsed 并隐藏图标。现在取消读取、拖动上下文及已排队的观察事件；不修改原收纳名单。回归覆盖晚到结果和点击前已入队的完整拖动。

## 验证与限制

本地：核心 73 测试；系统监控 608 断言；窗口缩略图 14 断言；截图像素/几何 357 断言；收纳事件/生命周期 71 断言；F4 存储/交互/动画回归通过。签名构建与最终提交的完整 CI 另存发布证据。

没有采集用户真实工作负载下的 CPU/GPU 曲线或长期内存增长，不能给出“提速百分比”或“全模块零缺陷”结论。系统 SCK 回调等待、私有收纳接口兼容性、原生菜单和拖动的实际手感，仍需用户更新后验证。同步保存大提示词库属于后续可测量的主线程风险，本轮未为优化牺牲退出时的数据持久性。
