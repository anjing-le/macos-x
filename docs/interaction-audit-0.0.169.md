# 连续使用流程检查

本轮按代码与隔离事件回归检查，未操作用户桌面。CI 覆盖两种原生架构；
真实拖动手感、系统权限和两台机器的实际传输仍需用户验收。

| 模块 | 检查的连续操作 | 本轮结果 |
|---|---|---|
| 截图／贴图 | 绘制、编辑、全部隐藏、重新显示、应用／取消、再次操作 | 修复编辑器与原图各自管理导致的显隐断点 |
| 录屏 | 框选、悬停选项、键盘操作、开始、同键停止、保存或取消 | 维持现有流程，运行状态、音频与实际编码回归 |
| 窗口切换 | 快速连按、方向选择、松手确认、Esc、窗口消失、进入截图 | 检查现有会话取消和过期选择防护，未据此新增行为 |
| 窗口布局 | 拖动到边缘、预览、反悔按 Esc、松手、晚到读取 | 补齐 Esc 取消；取消不能实际吸附，原按键继续交给所属应用 |
| 提示词 | 搜索、空结果、选中复制、Esc／外点取消、导入／编辑后退出 | 保留已有取消、焦点与正文保存规则，运行现有回归 |
| 菜单栏收纳 | 原生展开、点击应用菜单、移开、拖过苹果分界、停用 | 保留原生事件和右侧保护，运行现有回归 |
| 附近互传 | 选设备、退出选择、关抽屉、到 Finder 选文件、再开抽屉 | Esc 先退出设备选择；再次 Esc 或 ⌘W 关抽屉但不断连接 |
| 文件操作 | 选单文件、双击 Command、格式对应选项、执行／取消、再呼出 | 维持不支持则不弹菜单、原目录产出和不覆盖原件 |
| 电脑状态 | 打开、隐藏、再开、休眠恢复、停用、读数不可用 | 保留真实不可用状态、有界历史和后台采样生命周期 |

## 已修复的状态断点

F3 显隐改为管理整张贴图的当前表现形态，而非只隐藏原图 NSPanel。
编辑器准备过程中隐藏，或隐藏后异步应用／取消，均不能把窗口重新唤出。
重新显示只恢复原编辑器；全局显示不抢焦点，保留未完成文字。
隐藏时结束当前笔迹并释放输入监听、取色缓存与旧 OCR 请求，不创建额外轮询。

窗口布局复用现有事件监视器识别 Esc，只清理当前拖动、预览和异步世代。
普通键不做窗口查询，Esc 不被吞掉，也不应用布局。

互传抽屉按层级处理退出；关闭设备菜单或抽屉不隐式断开连接、撤销传输或更改接收选项。
不加“点击 Finder 就自动关闭”规则：用户需要先去 Finder 找文件再拖入，直接套用普通浮窗的
失焦关闭习惯会破坏这个流程。

## 尚需取舍的优化建议

文件操作的长任务状态目前需要再次呼出菜单查看。可进一步打磨完成反馈，但不应因此
自动激活 Finder、覆盖当前选区或连续弹窗。本轮不扩展格式、不增加通知权限或常驻入口。
这是交互改进建议，不作为已确认的转换错误或已实现功能宣传。
