# F3 格式化文字贴图

旧路径只把纯文字绘成一张图片：4096 字符和 1800 像素高度任一超限即失败；纯文字存在时也不使用 RTF，因此标题／加粗／表格会丢失。

## 新行为

- 短、无格式纯文字保持原有紧凑图片贴图。格式化或较长文字进入原生 TextKit 浮动文档，正文保持正常字号，可滚动、选字；顶部细握柄拖动，悬停显示关闭按钮。短文档按内容收紧。
- Markdown 使用原生字体及 NSTextTable；HTML 只解析本机剪贴板的白名单语义，不用 WebView，不运行脚本、样式或请求图片。RTF 在纯文字同时存在时也保留。图片剪贴板路径和图片编辑不变。
- 无选区 ⌘C 复制全文 PNG、RTF 和原始文字，接收应用选择兼容表示；有选区使用原生富文本复制。自有文档标记保证复制后再次 F3 仍按文档呈现。
- ⌘S 导出完整 PDF；⌘W／Esc 关闭。Shift-F3 显隐以及关闭后 F3 恢复，复用统一贴图生命周期；F4 成功保存全文图片后关闭文档。

## 资源与边界

- 单文档最多 100000 UTF-16 单元，HTML／RTF 输入最多 4MB；现有桌面贴图上限仍是 8 张。
- 阅读保持文本／版式和视口，不提前创建整张长图。主动导出的 PNG 最多 1600 万像素，编码全局单飞并在后台完成；关闭／取消使晚到导出失效，不覆盖剪贴板。
- 超出 PNG 预算仍可阅读全文、复制完整富文本／文字和导出矢量 PDF，不截断正文。F4 的图片存储限制保持原样。
- 不承诺像素复刻网页 CSS、远程图片、任意复杂 HTML 或数学公式；正文和表格按统一原生可读排版显示。
- 文档仅在内存中；不会自动保存剪贴板内容、原始业务案例或阅读历史。

## 验证

`zsh tools/run-text-pin-regression.sh` 使用公开的虚构排版示例、离屏视图与唯一测试剪贴板，检查长文末尾、标题／加粗、多表格／对齐、HTML 安全边界、RTF 优先、全文复制、滚动不截断、取消及导出字形方向。不展示窗口、不操作用户界面、不写通用剪贴板。真实 F3 路由另由 capture-access 回归覆盖，旧图片编辑继续跑 capture-editor 与 pin 回归。

实际应用复制、滚动、选择、粘贴、跨屏拖动和 F4 仍由用户 OTA 后验收。业务内容不进入公共测试素材，不改写或核验其中的事实结论。
