# 提示词 JSON v1

把以下格式交给 AI 整理提示词。客户端支持选择 JSON 文件或粘贴剪贴板 JSON，校验后确认导入。

```json
{
  "version": 1,
  "prompts": [
    {"id": "summary", "title": "总结", "content": "请总结以下内容：\n\n", "slot": 1},
    {"id": "rewrite", "title": "润色", "content": "保留原意，让表达简洁自然。"}
  ]
}
```

- `title`：轮盘和搜索显示的标题，最多 64 字。
- `content`：完整复制的内容，最多 16384 字 / 64 KiB；JSON 字符串换行写为 `\n`。
- `id`：可选，最多 64 字节；稳定 id 用于再次导入时更新同一条。省略时，相同标题和内容去重。
- `slot`：可选，1–10，从转盘正上方开始顺时针排列。省略就仅加入搜索库。替换位置不会删除旧提示词。

每批及整个库最多 500 条，JSON / 本地数据最多 4 MB。同一批 id、slot 不能重复。已有库合并导入，不整库覆盖。点设置里的「格式」可复制 AI 整理指令。
