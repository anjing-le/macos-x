# 文件操作 / File Actions

单文件、本地处理、按实际类型显示操作；不提供批量。功能池添加后启用，首页卡片进入设置后台，展示启停、使用说明与快捷键；仅快捷键和后台“打开文件操作”按钮呼出操作面板。默认双击左 Command，设置中可改右 Command、Option 双击或组合键；识别复用原共享输入层，不吞 Command 事件，打字、组合键与鼠标点击/拖动会取消未完成的双击。读取 Finder 仅在主动使用快捷键且 Finder 在前台时进行；不修改用户剪贴板获取选区。不支持的来源可拖入、粘贴文件 URL 或选择文件。

## 第一版能力

- 单帧图片：JPEG/PNG 输出，质量预设、等比缩尺寸。透明图导出 JPEG 须明确底色，方向归一化；压缩未变小保留原始字节，不虚报节省。多帧输入明确拒绝，不静默只取首帧。
- DOC/DOCX、RTF、ODT、PPT/PPTX、XLS/XLSX、ODS、CSV、EPUB：Markdown 或纯文字；ODP 第一版仅纯文字（样本中的矢量对象尚不能完整导出）。Markdown 内嵌栅格图片导出 assets 并在模型层写入相对链接，不替换用户正文；未知嵌入对象拒绝处理，不宣称完整保留。复杂表格仍受 Markdown 表达能力限制。
- PDF：指定页码导出 PNG，每次至多 20 页、累计 4800 万输出像素。锁定文件明确拒绝。PDF 转 Markdown 的实验质量未通过，因此不提供，也不打包 pdf-inspector。

## 任务、输出与资源

两个按需子进程：Swift/ImageIO/PDFKit 原生图像引擎与固定版本的 Rust anydoc 文档引擎。没有 Node/Python 运行时、云 OCR 或文件夹扫描。引擎仅在明确确认转换后启动，单一串行队列，结束退出；活动任务每 100 ms 检查退出、超时及资源，不进行空闲轮询。

输入最多 16 MiB，单图最多 2400 万像素，结果最多 64 MiB。文档核心的单项解压 16 MiB、累计解压 48 MiB、XML 节点 12 万、表格网格/展开 10 万；不是上游更宽松的默认值。工作进程超时 30 秒、观测 RSS 超过 384 MiB 时终止；RSS 采样是保护阈值，不是瞬时硬内存保证。

默认写入原目录的“转换结果 / Converted Files”，可选其他位置；任务先写私有隐藏目录，成功后在同卷以不覆盖方式移动。名称冲突编号，长中文名称按 UTF-8 字节收紧。失败/取消清理临时目录；取消后的旧回调只清理仍具有原文件身份的未确认结果，已确认及用户替换结果保留。停用、移除和退出撤销任务，退出等待活动任务清理完成。结果允许文件 URL 复制、拖出和 Finder 定位，不自动打开内容。

## 验证边界

`tools/run-file-actions-regression.sh` 使用临时目录、真实子进程、离屏 AppKit 与命名剪贴板验证图像、文档配图/正文、已列格式样本、PDF 页码、密码、损坏、同名、透明、取消、超时、结果身份和布局；英文以 `MACOSX_TEST_LANGUAGE=en` 运行。核心页码边界和 Command 双击由 `swift test` 覆盖，完整 CI 保留其他模块回归。

不自动操作用户 Finder、授权弹窗或聊天框，也不替用户安装升级；首次 Finder 授权、真实双击手感和不同接收应用的文件拖放由用户更新后验收。签名、构建、隔离回归与真实交互验收分别报告。
